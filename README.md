# BIT RUNNER（ビット・ランナー）

ブラウザのオフライン恐竜ゲームを土台にした、ドット絵のエンドレスランゲーム。
`index.html` をブラウザで開くだけで遊べます（ビルド不要）。

- 操作：クリックで小ジャンプ、長押しで大ジャンプ（上ルートへ）。一時停止とサウンドは画面右上のボタン
- 設計：[DESIGN.md](DESIGN.md)

# 焚火の夜（campfire）

夜の川辺で燃える焚火を、ただ眺めるだけの作品。
`campfire/index.html` をブラウザで開くだけで動きます（ビルド不要・外部素材なし）。

- 炎・煙・火の粉は**カールノイズ**（発散のない渦の流れ場）で動かしている。炎は上へ流れるノイズ場で舌を作り、火の粉は細かい渦でひらひら舞う。
- 薪のひび割れと熾火は、ゆっくりしたノイズで呼吸するように赤く明滅する。風が吹くと酸素で明るくなる。
- 音はすべて Web Audio で合成：ぱちぱち鳴る焚火（はぜる瞬間に火の粉が上がる）、スズムシ・エンマコオロギ・マツムシなどの虫の声、川のせせらぎ、ときどき吹き抜ける風と木の葉。
- 操作：最初にクリックで開始（音を鳴らすため）。あとはクリックで火をつつくだけ。右上で音のオン・オフ、音量の調整、全画面。しばらく動かさないとボタンは消える。
