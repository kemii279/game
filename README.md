# BIT RUNNER（ビット・ランナー）

ブラウザのオフライン恐竜ゲームを土台にした、ドット絵のエンドレスランゲーム。
`index.html` をブラウザで開くだけで遊べます（ビルド不要）。

- 操作：クリックで小ジャンプ、長押しで大ジャンプ（上ルートへ）。一時停止とサウンドは画面右上のボタン
- 設計：[DESIGN.md](DESIGN.md)

# ハザマ（LIMINAL）

ドット絵で描く、3D のリミナルスペース探索サバイバル。眠気に呑まれる前に、世界に紛れこんだ異物を7つ集めて目を覚ます。
`liminal/index.html` をブラウザで開くだけで動きます（ビルド不要・外部ライブラリなし）。

- 操作：WASD・矢印キーで歩く、マウスで見回す、Shift で走る、F ライト、1〜3 物資を使う、Q つねる（スマホは押して歩き、なぞって向きを変え、右下のボタンで物資を使う）
- `?seed=数字` を付けると別の世界になります
- 設計（世界観・眠気と正気のシステム・不気味さの演出・空間の生成方法・デザインディレクション）：[liminal/DESIGN.md](liminal/DESIGN.md)
